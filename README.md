# JTDA website demo

Compiled public review of the Jamaica Technology & Digital Alliance website redesign.

Explore the public website, /videos/, /review/members/, /review/admin/ and /build-progress/.

Member and staff records are fictional, with browser-local review interactions. Authentication, payments, email and live records are not connected. No real credentials or private member records belong in this repository.

The editable Next.js source is maintained separately. This repository holds only the compiled site for GitHub Pages.
