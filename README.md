# JTDA website demo

Compiled public review of the Jamaica Technology & Digital Alliance website redesign.

Explore the public website, /videos/, /sign-in/, /members/, /admin/ and /build-progress/.

Member and Super Admin sample accounts have a complete demo sign-in journey. Records and operations are fictional and browser-local. Production authentication, payments, email and live records are not connected. No real credentials or private member records belong in this repository.

The editable Next.js source is maintained separately. This repository holds only the compiled site for GitHub Pages.
